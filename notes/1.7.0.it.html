Novità di Canif 1.7.0

  • Wi‑Fi: impostazioni in base alla rete. Collegandoti a una rete nota, Canif applica le sue impostazioni (DNS, volume, audio disattivato, Mantieni attivo).
  • Uno strumento può restare attivo senza comparire nel menu di Canif (casella «Nel menu»).
  • Tastiera a ritmo consuma meno energia.
  • Canif è ora solo per Mac: le versioni Linux e Windows sono state interrotte.
